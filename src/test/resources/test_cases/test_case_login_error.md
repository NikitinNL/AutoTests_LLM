# AutoTests_LLM - Test Case Description

## Тест № 1: Получение сообщения "Invalid username or password!"

### Цель
Проверка отображения сообщения об ошибке при вводе невалидных данных при входе на страницу demoqa.com/login.

### Предусловия
- Браузер Chrome установлен и запускается.
- Доступ к сети и странице https://demoqa.com/login.

### Шаги

| № шага | Действие | Ожидаемый результат |
|--------|----------|---------------------|
| 1 | Перейти по ссылке: https://demoqa.com/login | Вход осуществляется. На странице браузера отображается форма Login. Форма содержит поля для заполнения: "UserName :" и "Password :", кнопки: "New User" и "Login". |
| 2 | Заполнить форму значениями: "UserName :" = Ivanii, "Password :" = Ivan7$7 | Поля формы успешно заполнены. |
| 3 | Нажать на кнопку "Login" | Получено сообщение на странице: Invalid username or password! |

### Постусловие
Сообщение об ошибке отображается корректно. Тест завершён.
